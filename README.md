# Document Q&A — Local RAG Pipeline

Ask questions about your PDF and text documents. Answers are grounded in the
actual content of your files and come with source citations. Everything runs
locally — documents are embedded with a local sentence-transformers model and
answers are generated by a locally hosted Ollama LLM. No data is sent to any
external API.

---

## How it works

```
                      ┌─────────────────────────────────┐
  PDF / TXT / MD  ──► │  Ingestion                       │
                      │  load → split → embed → FAISS    │
                      └────────────────┬────────────────-┘
                                       │  persisted to .vectorstore/
                      ┌────────────────▼─────────────────┐
  Question ────────►  │  Retrieval                        │
                      │  embed question → top-k search    │
                      └────────────────┬─────────────────┘
                                       │  relevant chunks + metadata
                      ┌────────────────▼─────────────────┐
                      │  Generation (Ollama)               │
                      │  prompt = system + context + q    │
                      │  stream tokens back to client     │
                      └────────────────┬─────────────────┘
                                       │
                      Answer + source citations
```

Embeddings: `all-MiniLM-L6-v2` (sentence-transformers, runs on CPU)
Vector store: FAISS with local persistence
LLM: any Ollama model (`llama3.2`, `mistral`, `phi3`, `gemma2`, …)

## Prerequisites

**1. Install Ollama**

Download from [ollama.com](https://ollama.com) and pull a model:
```bash
ollama pull llama3.2
```

**2. Install Python dependencies**
```bash
python -m venv venv
source venv/bin/activate    # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

---

## Quick start

**Start the API**
```bash
uvicorn api.main:app --reload
```

Interactive docs: `http://localhost:8000/docs`

**Upload a document**
```bash
curl -X POST http://localhost:8000/documents/ \
  -F "file=@report.pdf"
```

**Ask a question**
```bash
curl -X POST http://localhost:8000/query/ \
  -H "Content-Type: application/json" \
  -d '{"question": "What are the key findings?"}'
```

**Stream the answer token-by-token**
```bash
curl -X POST http://localhost:8000/query/stream \
  -H "Content-Type: application/json" \
  -d '{"question": "Summarise section 2"}'
```

**Or use the CLI to batch-ingest a folder**
```bash
python scripts/ingest.py path/to/my/docs/
```

## API reference

### Documents

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/documents/` | Upload and index a file |
| `GET` | `/documents/` | List all indexed documents |
| `DELETE` | `/documents/{doc_id}` | Remove a document and rebuild index |

### Query

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/query/` | Get a grounded answer with citations |
| `POST` | `/query/stream` | Same, but streams tokens as plain text |

```bash
GET /health
```
```json
{
  "status": "ok",
  "ollama_reachable": true,
  "model": "llama3.2",
  "documents_indexed": 3
}
```

## Configuration — `config/config.yaml`

| Key | Default | Description |
|-----|---------|-------------|
| `ollama.model` | `llama3.2` | Any model you have pulled via `ollama pull` |
| `ollama.temperature` | `0.1` | Low = more factual, High = more creative |
| `embeddings.model` | `all-MiniLM-L6-v2` | Local sentence-transformers model |
| `retrieval.top_k` | `4` | Number of chunks retrieved per question |
| `retrieval.chunk_size` | `500` | Characters per chunk |
| `retrieval.chunk_overlap` | `50` | Overlap between consecutive chunks |
| `storage.vector_store_path` | `.vectorstore` | Where FAISS index is persisted |

## Running tests

```bash
pip install pytest

Tests mock the FAISS index and embedding model so they run offline with no GPU
or Ollama instance required.

```

│   ├── main.py           FastAPI app, lifespan startup
│   ├── state.py          Shared state (store, config) to avoid circular imports

│   ├── retrieval/        Embeddings and FAISS vector store
│   └── generation/       LangChain RAG chain with Ollama

## Supported file types

| Extension | Loader |
|-----------|--------|
| `.pdf` | PyPDFLoader (page-level metadata) |
| `.txt` | TextLoader |
| `.md` | TextLoader |

Adding new types only requires updating `src/ingestion/loader.py`.

## Extending this

- **Better retrieval** — add MMR (maximal marginal relevance) to reduce redundant
  chunks in the context window
- **Conversation memory** — wrap the chain with `ConversationBufferMemory` to
  support follow-up questions
- **Re-ranking** — add a cross-encoder re-ranker step between retrieval and
  generation for higher answer precision
- **Multiple collections** — partition the FAISS store by project or user so
  questions only search the relevant document set
